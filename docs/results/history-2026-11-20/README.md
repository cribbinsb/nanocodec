What was measured:

- **Builds:** the last commit of every other UTC day on the integration branch and today's head, built now as plain release builds; 2026-11-06's build has no CBR rate control (`--qp` only), so the history starts on 2026-11-07, where H.264 alone is shown (that build's HEVC and AV1 refuse frame sizes that are not multiples of 8, most of the slice).
- **Points:** every speed-ladder preset each build shipped (Default, and Slow, Fast, Faster, Veryfast where present; before 2026-11-15 the files were `<codec>-fast`, `-faster`, `-fastest`, mapped to Fast, Faster, Veryfast; other files such as `h264-balanced` and `hevc-better` are not on the ladder and are left out), each with that build's own values, real-time CBR on the chart's ladder (150/300/600/1200 kbps at 720p30 scaled per clip, plus 40/75 kbps on the 14 clips whose curves need them), 150 frames, one key frame, our reconstruction scored (nceval.chart's engine).

- **Speed:** fps timed on AWS c8a (Zen 5), one core, by the chart's own timing (`aws_timing.py`): the chart's timing commands (three 720p clips, 150 frames, fixed QP found per build for about 600 kbps), each run back to back with x264 medium in rotated rounds on one c8a.large per part of a day's presets, the median time ratio to x264 medium times the chart's stored x264 medium time; every day is a plain release build (the overview's are PGO).
- **References:** the overview chart's encoders at today's versions, their quality re-averaged on the same clips, their fps as timed on the c8a.
- **Activity:** from git on the integration branch (first parent): commits (each row since the day after the previous row; the first from the first commit, 2026-11-06), lines added and removed by area (history.json `activity`), commits per agent where a trailer names it (Co-Authored-By / Claude-Session, Codex; none name Gemini in this period, others carry no agent trailer), and the lines of the `.rs` files under crates/ at the day's build. The code is written and maintained by AI coding agents under the direction of one person.
- **Captions:** each day's landings with the largest effect their own commit messages state, by codec (the numbers are those commits' own measurements on their own clip sets, not this chart's).
