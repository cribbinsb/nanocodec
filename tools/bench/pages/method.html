What each view records

The provenance each benchmark report carries. The procedure itself is docs/benchmark-procedure.md in the repository.

Not carried over from the earlier results pages

  • The earlier pages' figures (an older measurement procedure) are withdrawn and are not shown here.
  • Speed on other machines (Jetson, Zen, Graviton), the browser build and hardware encoders: these reports time one machine.
  • Frames per second: the reports give megapixels per CPU-second over each dataset's own clip sizes.
  • XPSNR, luma-only PSNR, the AOM CTC weighted PSNR and the per-rate-regime BD-J: not in the reports.
  • The Fixed QP standards lens (HM, VTM, the three fixed-QP columns), yardsticks and the cost of rate control against fixed QP: not measured by these reports. Buffer use is on the Rate control page (from these reports); spatial scalability is measured separately (the SVC page states its own conditions).
  • Per-clip tables, per-class means and AOM-CTC's separate A2 table: the report JSON carries set means only.
  • Command lines per encoder, tool versions and the demo links: the reports carry binaries' hashes; the commands are in the procedure document.
  • Our re-coded share (CBR): not in the report JSON.
