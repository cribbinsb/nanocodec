History of the headline chart

nanocodec's code was written and is maintained by AI coding agents (mostly Anthropic's Claude, also OpenAI's Codex and Google's Gemini) under the direction of one person. This page shows its encoders' presets on the overview chart and the Pareto frontier they form, one frame per day from 2026-11-07 (the first build with CBR rate control) to 2026-11-20, with the main landings and the git activity since the previous frame. Each frame is that day's last build, measured again now with one protocol, so the frames compare with each other. The dated charts of those days do not: their clip sets, zero line, timing machine and preset names changed during the period.

What this measures. Every preset each build shipped, on a fixed slice of the held-out fresh clips, not the full set the overview uses. Every build's fps were timed on AWS c8a (Zen 5), one core, the chart's machine, as plain release builds (the overview times PGO builds). The reference encoders are fixed points: today's versions, their quality on the same slice. How the chart is measured.
