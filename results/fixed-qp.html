Fixed QP: the standards lens

The charts elsewhere measure real-time CBR, where each encoder's rate control is part of the result. Here every encoder codes at fixed quantizers on 12 sequences of the AOM common test conditions in low delay, against x264 medium. Rate control is taken out, but each encoder's own searches and decisions are not: this compares encoders, not the coding tools of their formats.

Columns

  • Strict: ours on the fully static pattern of the test conditions: a fixed-strength QP cadence, no adaptive layers and a fixed rule for the second reference.
  • Profile: ours with its fixed-QP profile (rate.fixed_qp_profile): the frame-level pattern it uses when coding without rate control.
  • CBR settings: ours exactly as in CBR, only the quantizer fixed (profile off).
  • The reference encoders have one setting, so their value is the same in every column.
